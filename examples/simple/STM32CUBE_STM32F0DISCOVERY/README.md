# EVE-MCU-Dev Simple STM32Cube Example

[Back](../README.md)

The [STM32Cube](../../../ports/eve_arch_stm32/README.md#stm32cube) is used for this example.

## Setting Up the STM32Cube Example on STM32CubeIDE

The build environment depends on the presence of the STM32CubeMX and STM32CubeIDE. This can be setup following instructions in the [Integrated Development Environment for STM32](https://www.st.com/en/development-tools/stm32cubeide.html) page from the ARM website.

The "Drivers" need to be copied into the build environment by opening `simple_STM32F0DISCOVERY.ioc` in STM32CubeMX and clicking "Generate Code".

## Compiling the Simple STM32Cube Example on STM32CubeIDE

The instructions for compiling and programming the pico can be followed from the STM32CubeIDE User's Guide available from the [Introduction to STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html#documentation) page.
