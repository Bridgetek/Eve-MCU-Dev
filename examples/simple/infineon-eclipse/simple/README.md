# EVE simple example for Infineon PSoC 6 - Eclipse / ModusToolbox 3.8

This is a ModusToolbox 3.x single-core combined application for the
`CY8CPROTO-062S2-43439`. It communicates with a Bridgetek BT817 over SPI and
uses the migration layout described in Infineon KBA236134.

## Important: do not import this as a generic Eclipse CDT project

The archive intentionally does not contain `.project` or `.cproject` files.
Eclipse for ModusToolbox must generate its own project metadata. Generic CDT
metadata prevents the ModusToolbox Quick Panel from registering the
application and hides the application-specific Tools actions.

## First-time setup for Tools Package 3.8

1. Extract the archive to a normal writable directory. Do not work inside the ZIP.
2. Start **Library Manager** from the Windows Start menu or from the
   ModusToolbox Tools Package 3.8 installation.
3. In Library Manager, browse to this application directory:

   `examples/simple/infineon-eclipse`

4. Click **Add BSP**, select `CY8CPROTO-062S2-43439`, make it active, and click
   **Update**. This creates the application-owned BSP under:

   `bsps/TARGET_CY8CPROTO-062S2-43439`

5. Open a **modus-shell** terminal in this application directory and run:

   ```sh
   make getlibs
   ```

6. Start Eclipse for ModusToolbox 3.8 with a new or clean workspace.
7. Use one of these ModusToolbox import commands:

   - Quick Panel -> **Import Existing Application In-Place**
   - File -> Import -> ModusToolbox -> **Import Existing Application In-Place**

8. Browse to `examples/simple/infineon-eclipse` and complete the import.

After the ModusToolbox importer finishes, the Quick Panel should show Build
Application, Library Manager, Device Configurator, program and debug actions.

Do not use **General -> Existing Projects into Workspace**. That imports it as
a generic Eclipse project and the ModusToolbox Tools actions will not appear.

## KBA236134 layout

- `Makefile` contains `MTB_TYPE=COMBINED`.
- There is no `deps/TARGET_CY8CPROTO-062S2-43439.mtb` legacy BSP dependency.
- Library Manager creates `bsps/TARGET_CY8CPROTO-062S2-43439`.
- `libs` and any shared middleware are generated locally and are not shipped.
- `.project` and `.cproject` are generated by Eclipse during the in-place import.

## Default wiring

| EVE signal | CY8CPROTO-062S2-43439 pin |
|---|---:|
| MOSI | P9[1] |
| MISO | P9[0] |
| SCLK | P9[2] |
| CS# | P9[4] |
| PD# | P9[5] |
| GND | GND |

The pin definitions are in `source/eve_psoc6_config.h`.

## Build and program

From modus-shell:

```sh
make build
make program
```

The default EVE module configuration is `IDM20407A` (BT817, 800 x 480).

## Custom Tools 3.8 installation

The Makefile searches the normal per-user Tools Package 3.8 location. For a
custom installation, invoke make with a forward-slash path:

```sh
make getlibs CY_TOOLS_PATHS=C:/Infineon/ModusToolbox/tools_3.8
```
